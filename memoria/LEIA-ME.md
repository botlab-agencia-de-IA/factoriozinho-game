# 🧠 Memória do projeto

Esta pasta é o **diário do Factoriozinho**: o que foi combinado e feito em cada
conversa, escrito para ser lido de novo depois — por mim, quando a conversa
recomeçar do zero, e pelo Vandré, quando ele não lembrar onde paramos.

**Um arquivo por conversa**, com nome `AAAA-MM-DD-assunto.md`, do mais novo para
o mais velho. Dentro de cada um:

- **o que foi decidido** (e por quê — o porquê é a parte que se perde);
- **o que foi feito de fato** (arquivos que entraram, o que mudou no jogo);
- **o que ficou pendente**, para a próxima conversa começar sabendo.

## Onde cada coisa mora

| Isto | Vai para |
|---|---|
| Regra de design, número de máquina, decisão de jogo | `documentos/GDD.md` (a fonte da verdade) |
| Cor de material | `documentos/CORES.md` |
| Número de produção | `documentos/MATEMATICA.md` |
| **O que a gente combinou e fez numa conversa** | **aqui** |

Se uma decisão daqui virar regra permanente do jogo, ela sobe para o `GDD.md`.
A memória guarda o caminho; o GDD guarda o destino.
